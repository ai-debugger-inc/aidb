## What's New

### Skill System Fixes

Ported fixes from the [claude-skills-supercharged](https://github.com/jefflester/claude-skills-supercharged/pull/54) reference architecture addressing a design flaw in skill injection logic and improving guardrail reliability.

- **Fixed `autoInject: false` design flaw** - The flag was incorrectly blocking skills from injection even when AI scored them as relevant or affinity triggered them. `autoInject: false` now only gates the keyword-fallback path, allowing AI-scored and affinity-based injection to work correctly.
- **Guardrail skills exempt from 2-skill cap** - Guardrail skills (e.g., `code-reuse-enforcement`, `adapter-development`) are now always injected regardless of the domain skill cap. Only domain skills count toward the 2-skill limit.
- **Guardrail keyword union on long prompts** - After AI analysis, keyword hits are unioned to guarantee guardrail skills are included even when the AI under-scores them on long prompts.
- **Unified debug environment variable** - Consolidated scattered `AIDB_SKILL_DEBUG` and `AIDB_DEBUG_SKILLS` references into a single `DEBUG_ENABLED` constant controlled by `AIDB_DEBUG_SKILLS=1`.
- **Windows compatibility** - Added `renameSync` fallback with `unlinkSync` for Windows, where `renameSync` fails if the target file already exists.
- **Hook failure resilience** - Added `|| true` to the shell wrapper so hook failures do not break the conversation.
- **Removed dead code** - Removed `formatManualLoadSection` and unused `test:integration` script.

### CI/CD Improvements

- **Retry with exponential backoff for adapter downloads** - CI adapter build scripts now retry failed downloads with exponential backoff, improving resilience against transient network failures during GitHub release asset fetches.
- Added unit tests for the download retry logic.
